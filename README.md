# Bloc de Notas Online

## Descripción del proyecto

Este repositorio contiene el código fuente de **Bloc de Notas Online**, una aplicación web desarrollada como recurso educativo para el **Tutorial II: Desarrollo, integración y despliegue automatizado de una aplicación web en Microsoft Azure mediante Docker y GitHub Actions**.

El propósito del proyecto es demostrar cómo desarrollar, configurar y publicar una aplicación web en Internet utilizando **Microsoft Azure y GitHub**, abordando conceptos relacionados con el desarrollo frontend y backend, la infraestructura en la nube y la automatización de procesos de implementación.

El proyecto forma parte del material de apoyo del curso **Taller de Innovación y Emprendimiento Tecnológico**, impartido durante el segundo semestre de 2026 en la **Universidad Adolfo Ibáñez (Chile)**.

## Objetivo educativo

Proporcionar a los estudiantes un ejemplo práctico para comprender el proceso de publicación y administración de aplicaciones web mediante servicios de computación en la nube, utilizando herramientas del ecosistema Microsoft Azure e integración con repositorios de GitHub.
